
# Armo AI Console

پنل هوشمند مدیریت سرور Minecraft Paper با اتصال RCON.

## امکانات
- اتصال به کنسول سرور
- بررسی وضعیت سرور
- اجرای دستورات
- دستیار هوش مصنوعی فارسی
- تأیید قبل از اجرای دستور

## نصب
این پروژه برای اجرا روی Render آماده شده است.

## تنظیمات مورد نیاز
- ADMIN_PASSWORD
- RCON_HOST
- RCON_PORT
- RCON_PASSWORD
- GEMINI_API_KEY
- FLASK_SECRET

نکته: برای RCON از IP عمومی یا آدرس اختصاصی ارائه‌شده توسط هاست استفاده کنید، نه 127.0.0.1.
